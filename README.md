# procucev-transcription
Real-time transcription task

Author: Narasimha (narasimha55555)
Task: Procucev - Real-time Transcription using Gemini Live API

Live Demo
https://narasimha55555.github.io/procucev-transcription/

Features
- Real-time speech-to-text transcription
- Live transcript with interim results
- Start / Stop / Clear / Copy controls
- Mobile responsive dark UI
- Gemini Live API integration ready

How to Run
1. Open index.html in Chrome browser
2. Click Start Recording and speak
3. (Optional) Add Gemini API Key from aistudio.google.com

Tech Stack
- HTML5, CSS3, JavaScript
- Web Speech API (webkitSpeechRecognition)
- Gemini Live API
- Web Audio API
